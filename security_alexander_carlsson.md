Finns det någon risk med att vem som helst kan skicka anrop till ert API?

Ja, det finns en risk med det. APIet blir öppet för attacker och kan användas för syften som jag inte har räknat med. För att minska risken att obehöriga kommer åt vårat API kan vi t.ex införa autentisering med API nycklar eller använda CORS inställningar för att själva bestämma vem/vilka som har åtkomst till APIet.

Finns det någon personuppgift i projektet?

Vi hanterar inga personuppgifter i vårat projekt men om vi skulle göra det så skulle vi vara tvungna att följa GDPR, vi behöver då säkerställa att personuppgifterna behandlas säkert och lagligt.
